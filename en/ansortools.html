AnsorTools

A design tool in Uzbek: every command on a single “Ansor” ribbon tab, arranged in workflow order. Smart annotations recalculate themselves when moved or rescaled. Drawings to GOST and ShNQ codes.

How to get it Features

Features

For every stage of the drawing

Axes and grid

The structural grid in a single dialog, labelled with Uzbek Latin letters.

Walls, doors, windows

Wall types per ShNQ, corners join automatically; doors and windows in one click, tags added automatically.

Rooms and schedules

Room areas are found automatically; room, floor and finish schedules are compiled from the drawing.

Smart annotations

Levels, leaders, section marks, detail callouts, slopes — values update when moved.

Sheets and title block

A4–A0 frames, title block filled in once, sheets numbered automatically.

Site plan

Tree planting, paving, levels and slopes, coordinates, technical and economic indicators (TEP), parking, legend symbols.

No need to memorize command names

  • QQ — find any command or block by name (Cyrillic works too)
  • Every command shows its steps and clickable options at the bottom
  • 500+ ready blocks: furniture, doors and windows, trees, vehicles
  • The list of ShNQ codes — one button on the ribbon

How to get it

AnsorTools is licensed per computer. Updates arrive automatically over the internet.

  1. Contact usGet the installation package.
  2. InstallClose AutoCAD and run ornatish.bat.
  3. Send the codeSend us the request code shown on first launch.
  4. Start workingOnce the license is issued, press “Tekshirish” (Check) and the plugin starts immediately.
